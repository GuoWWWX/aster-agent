# 对话属性

> 对话属性与完整过程保存在 `conversations/<conversationId>/conversation.jsonl`。SQLite 对话字段在迁移期只作投影，最终结构见[第 22 篇](./22-JSONL对话存储与归属设计.md)。

## 1. 创建后不可变

不可变属性写在 `thread_header`，修改这些字段必须创建新对话。

| 字段 | 类型 | 规则 |
| --- | --- | --- |
| `conversationId` | UUID | 对话身份；目录名与事件引用均使用它 |
| `createdAt` | ISO 8601 | 创建时间 |
| `mode` | `persistent \| subagent` | 长期对话或临时 Subagent |
| `parentConversationId` | UUID / `null` | 固定父级；顶层为 `null` |
| `origin.creationMethod` | `user \| conversation \| subagent \| side \| team \| fork` | 创建方式 |
| `origin.sourceConversationId` | UUID / `null` | 来源对话；不等于父级 |
| `origin.sourceMessageId` | UUID / `null` | Fork 或消息触发点 |
| `origin.teamInstanceId` | UUID / `null` | 创建时的团队实例 |

## 2. 可变配置

初值写入 `conversation_created.properties`；后续只追加 `conversation_properties_changed`，不覆盖旧行。

| 字段 | 类型 | 规则 |
| --- | --- | --- |
| `title` | string | 对话标题，与 Agent 名称分开 |
| `agentId` | string / `null` | `settings.jsonc.agents` 中的配置 ID |
| `avatarIcon` | string / `null` | `null` 时可按对话 ID 生成像素头像 |
| `projectId` | UUID / `null` | 项目根目录通过 `projects.root_path` 查询 |
| `workspaceRootPath` | string / `null` | 仅表示无项目对话的手动绑定；默认工作区不重复保存 |
| `modelSelection` | object / `null` | 完整保存 `providerId + modelId + reasoning` |
| `permissionMode` | enum | 当前偏好；不是“允许一次”等临时授权 |
| `archivedAt` | ISO 8601 / `null` | `null` 表示未归档 |
| `pinOrder` | integer / `null` | `null` 表示未置顶 |

`modelSelection.modelId` 是供应商接口中的模型名称；同名模型必须用 `providerId` 区分。切换模型、思考、Agent 或权限只影响后续 Run，不改历史快照。

## 3. 关系与派生状态

这些信息不作为另一份可写对话属性：

| 信息 | 来源 |
| --- | --- |
| 项目名称、根目录 | `projectId -> db.sqlite.projects` |
| 当前团队、成员职责 | `db.sqlite` 团队实例与成员关系 |
| 默认无项目工作区 | `<ASTER_HOME>/workspaces/<conversationId>/` |
| `status`、`activeRunId`、`lastRunStatus` | Run 与生命周期事件 |
| `hasUnread`、最后阅读位置 | 阅读事件 |
| Subagent 列表和数量 | 查询 `parentConversationId + mode + status` |
| 消息、工具、审批、任务清单、压缩、用量 | 对应 JSONL 事件 |
| 删除进度 | `db.sqlite.conversation_deletion_tasks` |
| 侧栏、标签、滚动位置 | 本机 UI 状态 |

任务完成、显式结束、归档和用户删除是不同状态。Subagent 不再维护一套重复的专用状态字段。

## 4. 每次 Run 的实际快照

对话配置是“下次运行偏好”；每次 Run 还必须冻结：

```json
{
  "agentId": "agent-dev",
  "modelSelection": {
    "providerId": "provider-a",
    "modelId": "model-a",
    "reasoning": { "kind": "effort", "value": "high" }
  },
  "permissionMode": "ask_before_changes",
  "projectId": "project-a",
  "projectName": "项目 A",
  "projectRootPath": "D:/Code/project-a",
  "workspaceRootPath": "D:/Code/project-a"
}
```

快照不保存 API Key。项目搬迁、配置删除或当前模型切换后，历史 Run 仍按当时事实展示。

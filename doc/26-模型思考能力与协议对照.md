# 模型思考能力与协议对照

核对日期：2026-10-15。范围为本应用四种协议下常见、公开文档可核实的文本模型。私有部署、网关重命名与动态别名可能不同；此表不是所有已部署模型的穷举，未知模型不自动虚构档位。

## 1. 协议与模型分开判断

| 协议 | 档位参数 | 说明 |
| --- | --- | --- |
| OpenAI Chat Completions | `reasoning_effort` | 多家供应商兼容此格式；接受的值由具体模型和服务决定。 |
| OpenAI Responses | `reasoning.effort` | 与 Chat 的字段位置不同；支持 Chat 不等于支持 Responses。 |
| Anthropic Messages | `output_config.effort`；旧模型用 `thinking.budget_tokens` | effort 和数值预算不能混为同一组固定档位。Claude adaptive 与第三方兼容服务的 thinking 参数也不能盲目互用。 |
| Google Gemini | `generationConfig.thinkingConfig.thinkingLevel` / `thinkingBudget` | 原生服务主要用于 Gemini。Gemini 另有 OpenAI 兼容接口，不能直接混用两种请求体。 |

## 3. 本地配置与设置页

保存到当前 Aster 数据目录的 `settings.jsonc`，字段为 `modelCatalog.reasoningProviders` 与 `modelCatalog.reasoningRules`。默认目录为 `~/.aster`，Windows 通常为 `C:\Users\<用户名>\.aster\settings.jsonc`；自定义数据目录随现有存储位置设置走，不写入项目仓库，也不存入对话数据库。

原因：这是用户维护的非敏感能力配置，需要可读、可备份、可迁移，与已整合的 modelCatalog 属于同一配置事实。沿用 JSONC 原子更新，保留其他字段与注释；密钥仍由原凭据模块处理。

每个目录供应商保存 id、名称、内置图标、可选上传 Logo、支持的 apiFormats 和可选 HTTP/HTTPS 官方文档地址 sourceUrl。图片使用本地 data URL 保存，不依赖远程资源或绝对文件路径；上传支持 PNG、JPEG、WebP，文件最大 256 KB，协议禁止远程 URL、SVG 与超长内容。放大的 Logo 预览可直接点击上传，鼠标悬停／键盘聚焦显示上传反馈；与右侧内置图标选择器同排，不再有独立上传按钮。目录供应商不是含 API Key 和请求地址的连接供应商。模型配置底部的“查看官方文档”使用所属供应商的地址。

每条规则保存 id、providerId、modelKey、名称、模型匹配模式、apiFormat、options，可附说明和官方来源。一个供应商的同一模型按 modelKey 分组，每个协议最多一条规则；名称与匹配模式在该模型各协议之间共用，选项独立保存。后匹配规则优先；空 options 表示没有显式档位。供应商取消勾选协议时不删除对应规则，但该协议规则不再参与目录解析，恢复勾选后恢复。旧配置没有 reasoningRules 时读取当前内置规则；显式空数组保持为空，旧平面自定义规则在打开编辑器时补入分组，直到点击保存才落盘。旧 modelCatalog.models 的上下文窗口与其他自定义内容不被覆盖。

读取或保存目录时，若检测到完整且原顺序保留的旧 142 条精确默认记录，则原子升级为能力分组；修改过的名称、档位等记录作为精确覆盖保留在分组规则之后，自定义后缀及供应商编辑保持不变。缺失、删除、重排或修改过匹配条件的目录不自动合并，避免恢复用户删除的内容。升级写入失败保留原文件并报错，成功后重复读取不再写入。

`matchMode` 可选 exact（指定完整模型 ID）、glob（* 通配符）、regex（RE2 正则表达式）；旧规则缺少此字段时保持 glob 语义。每行一个规则，exact/glob 还接受逗号分隔；regex 保留量词内部逗号，不接受 JavaScript 的 /…/ 分隔符。匹配忽略大小写，兼容完整 ID 和最后一段供应商前缀后的模型名。正则由固定版本 re2js 在 Schema 保存边界校验，前后端采用同一无回溯引擎，非法表达式不能落盘；不支持的回溯引用／前瞻也会报错。重叠规则仍遵循后面的规则优先。目录头部的“补齐内置模型”仅补缺少的供应商和模型协议记录，新条目放在旧规则前面，保留已修改名称、图标、档位及自定义覆盖。

设置 → 智能体 → 推理程度：左侧卡片中选择供应商／模型，顶部添加供应商；供应商行支持弹框编辑、添加模型、删除。每家供应商内按名称中的模型版本数字从新到旧显示，同版本按名称自然排序，无版本名称排在后面；仅排序视图，不改变配置保存顺序和后匹配优先级。模型行可删除整组协议配置。删除均先确认，实际落盘仍通过页面的“保存修改”。右侧按“基本配置”“推理档位”分组，各有卡片外标题和分隔线、独立深色内容卡片，沿用页面滚动和主题规范。对话协议下拉只展示所属供应商勾选的协议；切换协议后可独立增删、启用、编辑、排序档位，或恢复当前协议内置默认。供应商弹框的“确定”只更新页面草稿，“取消”放弃该弹框修改；写入失败保留草稿供重试。新建或发现模型采用该目录；已有连接供应商模型的显式档位保留，可在原推理强度编辑器点恢复默认应用当前目录。

运行中的 Run 继续使用创建时的模型与推理快照，不因修改目录而重发请求。本批的旧式开关扩展支持边界在上表明确列出；没有将第三方网关未承诺的协议组合自动加入目录。

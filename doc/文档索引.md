## 当前已确定

- 一个 Git 仓库。
- `apps/web` 是唯一 React UI，可在浏览器运行并作为 Electron Renderer。
- `apps/desktop` 只负责 Electron Main、Preload 和本机能力装配。
- 复用 `md-king` 的视觉与交互合同；外壳按新架构重实现，编辑器和预览按受测试保护的最小闭包迁移。
- 第一阶段是由长期负责人协调的 Windows 本地编码 Agent 团队。
- Node.js + TypeScript 承担 Agent Runtime 和本机工具。
- 模型层支持多个 Provider 和 Model Profile；OpenAI-compatible 只是其中一种接入方式。
- SQLite 保存会话主数据，Artifact 目录保存大内容。
- 模型发起的写入、Patch 和命令逐次审批。
- Web 第一阶段是同 UI 的浏览器预览，不包含远程完整 Agent Server。
- DOCX、Word/WPS、WSL、SSH、交互式 PTY 和插件市场不进入 MVP。
- 团队可登记多个项目，但每个可执行任务只能绑定一个主项目；跨项目请求拆成项目级子任务。
- 简单任务直接执行，只有存在独立支线或真正可并行工作时才创建 Subagent 或团队。
- UI 使用 shadcn/ui `radix-nova`、Radix、Tailwind CSS 4、CVA 和 Lucide 的同一套设计系统。
- 复用 `md-king` 的视觉与交互合同，但不复制其巨型页面、完整全局 CSS 和直接 Tauri 调用。
- 每个 Agent 都有可查看、可恢复的逻辑对话 Thread，但不独占 OS 线程或进程；新 Agent 默认继承父对话模型，用户可以指定或修改。
- MCP 和 Skill 是基础扩展能力，但不能绕过本产品的权限、审批和项目边界。

## 开工入口

第一次代码实现按[开工准备与首批任务清单](./04-开工准备与首批任务清单.md)执行，范围对应[迁移与开发计划中的首个代码批次](./03-md-king迁移与开发计划.md#8-首个代码批次)：

```text
初始化 Git 与 pnpm workspace
创建 apps/web、apps/desktop、packages/protocol
建立 AgentClient 与 MockAgentClient
按 md-king 视觉合同重实现主题、AppShell、标题栏和最小布局
让同一 UI 同时在浏览器和 Electron 中启动
```

首个代码批次不接模型、SQLite、Shell 和完整 Markdown 编辑器。完成双宿主 UI 与安全 IPC 骨架后，再按开发计划逐批推进。
